Generated by `python3 scripts/build-explorer-japanese.py`. To update, replace the
local source dump with the current JMdict JSON export and rerun the script (keep
published dictionary data current, at least monthly, per the source terms).

Transformations: deduplicate forms, join English glosses within each sense,
retain applicable readings for kanji spellings, and include definitions for
kana-only entries, common kana forms and entries marked usually written in kana.
Uncommon phonetic aliases of kanji-only vocabulary are omitted. This is not a
complete replacement for JMdict. The original graph and classic dictionary
partitions are unchanged.

`kana.json` is an exact-search vocabulary index. Numbered files load on demand,
using the sum of UTF-16 code units modulo 100, matching the existing dictionaries.
The full supplement is approximately 25 MB; a lookup downloads only its partition.
